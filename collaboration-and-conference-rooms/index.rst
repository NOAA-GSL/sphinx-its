Slack
^^^^^

Slack has been approved for use in ESRL by the ISSO and the System Owner. It
is authorized at a low-risk level. Please see the Slack use Rules of Behavior for
information on restrictions and guidelines.

Rules of Behavior for Slack
"""""""""""""""""""""""""""

* Keep NOAA data off Slack systems
* Do not connect NOAA Google for Government apps to Slack.
* Credentials and credential management on Slack must adhere to all NOAA policies.
* Two-factor authentication must be enabled for all workspaces.
* All All apps must be pre-approved by the admin.

Remote Access Application
^^^^^^^^^^^^^^^^^^^^^^^^^

* Windows Remote Desktop (RDP)
* Google Chrome Remote Desktop

  * Chrome Remote Desktop allows you to remotely control a chrome instance on
    a remote machine, as long as the system is setup and listening. 
  * Information can be found `here: <https://remotedesktop.google.com>`_.
  
* Apple Remote Desktop
* SSH (Secure Shell) - for Linux and MacOS systems
