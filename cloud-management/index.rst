Cloud Management
================

GSL has access to three Cloud Providers:  AWS, Microsoft Azure, and Google Cloud.  
All Cloud resources are managed by OAR HQ, and GSL works closely with the OAR HQ
Cloud Administrators to ensure our environments are 
appropriate for GSL and NOAA needs.

GSL Cloud resources use environments within the OAR HQ FISMA boundary. 
Requirements are set at the FISMA level, and GSL maintains a Cloud Management 
Team which works closely with the HQ team and AWS engineers.  There are security guardrails 
in place to ensure that permissions are appropriately assigned, and each project is required to 
have documented roles, responsibilities, and data flow diagrams.

In addition, GSL has a process in place to review and approve every project. This process 
ensures that the projects meet security requirements, have the appropriate tags and 
permissions, and are reviewed by the GSL Cloud Engineer, who can offer assistance when 
needed.


Where To Start?
---------------

To create a new Cloud Project, you must first submit a 
`Cloud Project Request Form
<https://docs.google.com/forms/d/e/1FAIpQLSdKQ6keP3Rr7WnbdoZsaPa6noVSTvqS8UKPwIikRxwvaTPh2w/viewform>`_.
This form
is reviewed by the Cloud Project Review Board, which is made up of GSL Cloud Engineers and
OAR HQ Cloud Administrators.
If the project is approved, you will receive an email with more 
information. If the project is not approved, you'll receive an explanation with next steps.

You will also need to have an account with the specific cloud service provider.
If you already have an account, you can use that account to access the GSL Cloud resources.
If not, submit a request to **help.ssg.gsl@noaa.gov**, and request that an 
account be created.  By default, GSL users will be granted the ‘OAR_ESRL_Developer’ role.
Currently most GSL work is done in AWS, and our development space is in us-east-2.
